---
name: "Check against criteria"
description: "Compare a ticket's notes with its acceptance criteria, one by one."
---

1. Read the ticket description and the notes kept on its branch.
2. For each acceptance criterion write met, partly met or not met.
3. Quote the words from the notes that show it. If the notes say nothing, mark it not met.
4. List what the notes should say but do not.
5. Finish with one recommendation: ready for review, or the first thing to finish.
